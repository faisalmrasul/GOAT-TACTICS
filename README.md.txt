# ⚽ GOAT Tactics: Captains of History

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://YOUR-APP-NAME.streamlit.app)

> Draft legends. Command history. Win the Eternal Trophy.

A turn-based tactical football game where you pick one of five GOAT captains,
build a 4-3-3 squad of historic icons, and battle through a 4-match tournament
against automated XI teams.

## ✨ Features
- **5 GOAT Captains** — Messi, Ronaldo, Pelé, Maradona, Ronaldo Nazário — each with a unique special ability
- **Squad Draft** — 20+ historic icons (Maldini, Beckenbauer, Zidane, Buffon, Ronaldinho, Cruyff, Henry, Puskás…)
- **8-Round Turn-Based Matches** — tactical decisions, dice rolls, momentum, stamina, halftime boost
- **Captain Ability System** — with visual cooldown timers
- **Live Commentary + Audio SFX** — whistle, kick, goal, ability
- **Post-Match Report** — stats, goalscorers, Player of the Match, tournament standings
